# 🥗 샐러리아 (SALARIA) 메뉴판 가격 · 옵션 · 영양성분 탐색기 & 영수증 계산기

매장 실물 메뉴판의 **9개 카테고리 전 메뉴(115종)** 가격과 옵션(통밀 변경 `+500원`, 드레싱·소스 7종, 커리 맛, 그릭요거트 꿀 선택), 실물 메뉴 사진(96종), 그리고 공식 영양성분표(73종)를 한눈에 비교하고 **실물 영수증 형태**로 주문 금액과 총 영양성분을 출력할 수 있는 웹앱입니다.

## ✨ 주요 기능
- **전 메뉴 115종 수록**: 샌드위치(18), 랩(6), 포케 랩(5), 포케(18), 샐러드(22), 단백질 도시락(11), 커리 덮밥(12), 그릭요거트(5), 푸드(18)
- **맞춤 옵션 선택**:
  - 우유식빵 / 통밀식빵(`+500원`), 일반 또띠아 / 통밀또띠아(`+500원`) 개별 및 일괄 변경
  - 포케/도시락 소스(7종), 샐러드 드레싱(7종), 커리 덮밥 맛(오리지널/스파이시), 그릭요거트 꿀(O/X) 선택
- **다중 정렬 & 빠른 필터**:
  - 낮은 가격순, 높은 단백질순, 낮은 열량순, **가성비 단백질순(1,000원당 단백질 g)**, **고밀도 단백질순(100kcal당 단백질 g)** 등
- **🧾 실물 영수증 & 영양성분 영수증 출력**:
  - 담은 메뉴와 옵션을 영수증 형태로 모아보고 수량 조절, 텍스트 클립보드 복사, 인쇄/PDF 저장 지원
